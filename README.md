# FarmMaker

## 🎮 프로젝트 개요
본 프로젝트는 팀 프로젝트로 진행되었습니다.
본 프로젝트는 포트폴리오 용도로 제작되었으며, 일부 기능은 미완성 상태입니다.

## 프로젝트 소개
플레이어는 자원을 채집하고 작물을 재배하며, 동물과 상호작용할 수 있는 농장 경영 시스템을 경험할 수 있습니다.

## 사용 기술
- Unity
- C#
- FSM 기반 AI 구조 설계 (상태 전이 기반 행동 제어)

## 👨‍💻 담당 역할
- 메인 프로그래머
- 게임 핵심 시스템 설계 및 전체 코드 구현
- FSM 기반 AI 구조 설계 및 개발
- 플레이어 / 상호작용 / 채집 시스템 구현

## 🧩 주요 구현 기능

### 🎮 플레이어 시스템
- 캐릭터 이동
- 체력 / 스태미나 시스템
- 카메라 조작 (각도 조절, 줌 인/아웃)

### 🐾 동물 & AI 시스템
- 간단한 동물 AI (행동 FSM 기반)
- 애완동물 AI
- 동물 상호작용 (쓰다듬기, 먹이주기)
- 친밀도 기반 동물 소환 시스템

### 🎒 상호작용 & 아이템 시스템
- 도구 획득 / 버리기
- 음식 섭취 및 동물 먹이주기
- 상호작용 가이드 UI 출력

### 🪓 채집 시스템
- 도구 기반 채집 시스템
  - 도끼 → 나무 채집
  - 곡괭이 → 돌 채집

### 🐄 물리 & 행동 시스템
- 동물 들어올리기 / 내려놓기
- 동물 던지기 (물리 기반 상호작용)

### 🖥 UI 시스템
- 통합 메뉴 UI 제작
